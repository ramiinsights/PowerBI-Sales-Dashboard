# 📊 Sales Dashboard (Power BI)

## 🔍 Project Overview

This project is a Sales Dashboard built using Power BI. It helps analyze sales performance, product categories, and group-wise quantity.

## 📈 Features

* Daily Sales Trend Analysis
* Product Group Segmentation
* Item-wise Quantity Comparison
* Group-wise Performance Analysis
* Interactive Date Filter

## 📊 Key Insights

* Highest sales from Outfits and New Devices
* Sales dropped on Day 5 and recovered later
* Devices category dominates overall sales

## 🛠 Tools Used

* Power BI
* Excel / CSV Dataset
